LopGui
Возможности Установка GitHub

Минималистичный GUI без зависимостей

Легковесный Python-фреймворк с прямым вызовом Win32 API через ctypes. Никаких громоздких библиотек, абсолютная плавность и кастомный дизайн.

Скачать с GitHub Быстрый старт
main.py (просто добавь lopgui.py в проект) 
from lopgui import App, Button

# Никаких pip install — только чистый код
app = App(title="LopGui App", width=800, height=500)

app.add(Button(
    app, 
    text=".Click me!", 
    command=lambda: print("Кнопка нажата!")
))

app.run()

⚡ Zero Dependencies

Никаких тяжелых зависимостей вроде PyQt или Tkinter. Используются только встроенные библиотеки Python и нативный `ctypes`.

🎨 Кастомный дизайн

Собственная темная тема, кастомные элементы управления, скругленные углы и фирменный акцент #b026ff.

🚀 Двойная буферизация

Абсолютное отсутствие мерцания (flickering) при перетаскивании, изменении размера и наведении мыши благодаря ручному управлению буфером GDI.
